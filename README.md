# Snake

A Snake game in Kotlin with [libGDX](https://libgdx.com/) and [KTX](https://libktx.github.io/), generated with [gdx-liftoff](https://github.com/libgdx/gdx-liftoff). It runs on desktop and in the browser, phones included.

## Play

| Action | Keyboard | Touch screen |
|---|---|---|
| Start a run | an arrow key | tap the board or swipe |
| Turn | arrows, WASD or ZQSD | swipe |
| Pause / resume | Space | the "II" button, then Resume |
| Back (pause, then main menu) | Escape | Android Back key (native build only) |

- One food = one point. The snake speeds up a little with each food.
- The game is lost when the snake hits a wall or itself, and won when the snake fills the board.
- The best score and the sound and music settings are saved between sessions (files in `save_data/` on desktop, browser storage on the web).
- Texts follow the device language: French or English.

## Run

Use `./gradlew` on macOS or Linux, `gradlew.bat` on Windows.

- Desktop: `./gradlew lwjgl3:run`
- Web, local server on http://localhost:8080: `./gradlew teavm:run`
- Web build only, output in `teavm/build/dist/webapp`: `./gradlew teavm:buildJavaScript`
- Compile check: `./gradlew core:compileKotlin teavm:buildJavaScript`
- Tests: `./gradlew core:test`

## Publish the web version

- GitHub Pages: every push to `master` builds and deploys the game with `.github/workflows/publish-web.yml`. One-time setup: repository Settings > Pages > Source: "GitHub Actions". The game is then at https://arthurcaron.github.io/Snake/ (subject to your repository visibility and GitHub plan).
- Any other static host, or itch.io (HTML game): `./gradlew teavm:webZip`, then upload `teavm/build/dist/Snake-web.zip`.

## Icons

The window, package and browser icons are generated from a sprite: `java tools/make-icons/MakeIcons.java <sprite.png> .` from the repository root.

## Modules

- `core`: the game, shared by all platforms.
- `lwjgl3`: desktop launcher.
- `teavm`: web launcher and build.
- `android`: Android launcher. Needs the Android SDK.
- `tools/asset-catalog-generator`: generates typed accessors for the assets.

## Assets

- Edit the files in `sourceAssets/`. The `assets/` folder is generated by Gradle and ignored by git.
- `sourceAssets/textures` is packed into a texture atlas; fonts, sounds, music and translations are copied.
- After a build, use the generated `TextureAssets`, `SoundAssets`, `MusicAssets` and `FontAssets` instead of file paths.
- The loss, victory and pause sounds are generated stand-ins, even though their filenames no longer use the `placeholder_` prefix.
