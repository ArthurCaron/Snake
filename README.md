# Snake

A Snake game in Kotlin with [libGDX](https://libgdx.com/) and [KTX](https://libktx.github.io/), generated with [gdx-liftoff](https://github.com/libgdx/gdx-liftoff). It runs on desktop and in the browser, phones included.

## Play

| Action | Keyboard | Touch screen |
|---|---|---|
| Start a run | an arrow key | tap the board or swipe |
| Turn | arrows, WASD or ZQSD | swipe |
| Pause / resume | Space | the "II" button, then Resume |
| Back (pause, then main menu) | Escape | Android Back key (native build only) |

- One food = one point. The snake speeds up a little with each food.
- The game is lost when the snake hits a wall or itself, and won when the snake fills the board.
- The best score and the sound and music settings are saved between sessions (files in `save_data/` on desktop, browser storage on the web).
- Texts follow the device language: French or English.

## Run

Use `./gradlew` on macOS or Linux, `gradlew.bat` on Windows.

- Desktop: `./gradlew lwjgl3:run`
- Web, local server on http://localhost:8080: `./gradlew teavm:run`
- Web build only, output in `teavm/build/dist/webapp`: `./gradlew teavm:buildJavaScript`
- Compile check: `./gradlew core:compileKotlin teavm:buildJavaScript`
- Tests: `./gradlew core:test`

## Publish the web version

The game is published on itch.io as an HTML game. The GitHub repository stays private.

`./gradlew teavm:webZip` builds `teavm/build/dist/Snake-web.zip`, with `index.html` at the root, the layout itch.io expects.

### Automatic: GitHub Action

The `itch` branch is the published version. Every push to `itch` builds the zip and pushes it with butler, by `.github/workflows/publish-itch.yml`. A push to `master` publishes nothing.

#### Publish from `master`

1. Make sure that your local `master` is the version to publish: `git checkout master`, then `git pull`.
2. Push `master` to the `itch` branch of GitHub:

   ```
   git push origin master:itch
   ```

   This command does not need a local `itch` branch. The first time, it creates the `itch` branch on GitHub. After that, it moves `itch` forward to `master`.
3. On GitHub, open the Actions tab and follow the "Publish to itch.io" run. When it is green, the new version is on itch.io.

If the push is refused as "non-fast-forward", `itch` has a commit that `master` does not have. Look at it with `git log master..origin/itch` before you overwrite it with `git push --force origin master:itch`.

To publish an older state, push its commit instead: `git push --force origin <commit>:itch`.

To publish again without a new commit, run the workflow by hand: Actions tab > "Publish to itch.io" > Run workflow, with the `itch` branch selected.

#### One-time setup

1. On itch.io, create the project: Kind of project "HTML", then save it once as a draft.
2. On itch.io, Settings > API keys: generate a key.
3. On GitHub, repository Settings > Secrets and variables > Actions:
   - secret `BUTLER_API_KEY`: the API key;
   - variable `ITCH_USER`: your itch.io user name;
   - variable `ITCH_GAME`: the project name in its URL (`https://<user>.itch.io/<game>`).
4. Publish from `master` once, as above.
5. On the first publication only, edit the project on itch.io: check "This file will be played in the browser" on the `html5` upload, set the viewport size, and check "Mobile friendly".

### Manual: butler on your machine

1. Install butler: https://itch.io/docs/butler/installing.html, or install the itch app, which ships it.
2. Log in once: `butler login`.
3. Build the zip: `./gradlew teavm:webZip` (`gradlew.bat` on Windows).
4. Push it: `butler push teavm/build/dist/Snake-web.zip <user>/<game>:html5`.
5. Check the upload: `butler status <user>/<game>:html5`.

butler only uploads the files that changed. The `html5` channel name is free: keep the same one on every push, so itch.io updates the same upload.

Without butler, upload `Snake-web.zip` by hand on the project's edit page.

## Icons

The window, package and browser icons are generated from a sprite: `java tools/make-icons/MakeIcons.java <sprite.png> .` from the repository root.

## Modules

- `core`: the game, shared by all platforms.
- `lwjgl3`: desktop launcher.
- `teavm`: web launcher and build.
- `android`: Android launcher. Needs the Android SDK.
- `tools/asset-catalog-generator`: generates typed accessors for the assets.

## Assets

- Edit the files in `sourceAssets/`. The `assets/` folder is generated by Gradle and ignored by git.
- `sourceAssets/textures` is packed into a texture atlas; fonts, sounds, music and translations are copied.
- After a build, use the generated `TextureAssets`, `SoundAssets`, `MusicAssets` and `FontAssets` instead of file paths.
- The loss, victory and pause sounds are generated stand-ins, even though their filenames no longer use the `placeholder_` prefix.
