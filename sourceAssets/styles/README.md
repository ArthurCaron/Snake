# Styles

Each folder is a complete look for the game, generated by `tools/style-generator`.
The game uses the style that is installed in `sourceAssets/textures/game/skin`. It is `desert` by default.

| Folder | Look |
|---|---|
| `desert` | Cartoon cell shading: thick dark outlines, sand ground, teal snake. Installed. |
| `oasis` | Same style, green floor, orange snake, mango. |
| `tundra` | Same style, snow and ice, purple snake, red berry. |
| `volcano` | Same style, basalt and lava colors, yellow snake, ice fruit. |
| `dusk` | Same style, purple dunes at night, orange snake, turquoise fruit. |
| `lagoon` | Same style, sand and sea colors, coral snake, yellow fruit. |
| `neon` | Other style: glowing outlines on a night background. |
| `gameboy` | Other style: 4-tone green pixel art. Pair it with a pixel font in Settings. |
| `laser` | Other style: white-hot cyan and pink laser lines, light pools on the floor. |
| `laser-sunset` | Same as `laser`, orange snake and cyan fruit. |

`previews/<style>.png` shows the menu, a game and the end screen of each style. `previews/all.png` puts every style side by side. `previews/marks.png` shows the back marks. `previews/fruits.png` shows the ten fruits of every style.

## Try a style

```bash
python3 -m venv .venv && .venv/bin/pip install -r tools/style-generator/requirements.txt
.venv/bin/python tools/style-generator/generate.py --install oasis
./gradlew lwjgl3:run
```

Laser styles set `snakeGlow` and `fruitGlow` in `Palette.kt`: the game then draws an additive light under the snake and the fruit. The other styles keep these colors transparent.

`--install` copies the sprites, the splash and loading images, and the desktop, Android and web icons. The colors stay in `core/src/main/kotlin/fr/mwet/snake/tuning/Palette.kt`, edited by hand: each style lists its colors in `palette.json`.

## Change a style

Colors live in `tools/style-generator/palettes.py`. Add an entry to create a new environment, then run:

```bash
.venv/bin/python tools/style-generator/generate.py <name>
```

Without a name, the script regenerates every style.

## Colors and marks

The snake and the fruit are drawn in two layers: a gray layer that the game tints, and a fixed layer (outline, eyes, leaves, laser cores).
So colors and marks change without new images. Edit `Palette.kt` to try a value, or the palette in `palettes.py` to keep it:

| `Palette.kt` | `palettes.py` | Effect |
|---|---|---|
| `snake` | `snake_tint` | Snake color at the start of a game. |
| `marks` | `mark_color` | Color of the marks on the back, independent from the snake. |
| `markShape` | `mark_shape` | `Diamond`, `Circle`, `Square`, `Star`, `Chevron` or `Heart`. |
| `fruits` | `fruit_colors` | Fruits that can appear, as `FruitStyle(kind, color)`. Each new fruit is a random entry of the list. Kinds: `Apple`, `Strawberry`, `Cherry`, `Banana`, `Grapes`, `Orange`, `Pear`, `Lemon`, `Watermelon`, `Prickly`. Without `fruit_colors`, each kind keeps its natural color; with it, the colors are spread over the kinds. |
| `snakeTakesFruitColor` | `snake_takes_fruit_color` | The snake takes the color of the fruit it eats, from the head to the tail. |
| `snakeGlow`, `fruitGlow` | `snake_glow`, `fruit_glow` | Strength of the light on the floor; `0` turns it off. |
